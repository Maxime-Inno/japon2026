# 📲 Installer « Japon 2026 » sur ton téléphone Android

L'appli doit être publiée une fois sur Internet (adresse https) pour pouvoir être installée sur le téléphone et fonctionner hors ligne. Ensuite, elle s'ouvre depuis une icône, comme une vraie application.

## Étape 1 – Publier l'appli (une seule fois, depuis le PC, ~10 min, gratuit)
1. Crée un compte gratuit sur https://github.com (ou connecte-toi).
2. En haut à droite : **+ → New repository**. Nom : `japon2026`. Coche **Public**. Clique **Create repository**.
3. Sur la page du dépôt : **uploading an existing file** (ou **Add file → Upload files**).
4. Dézippe `Japon_2026_App.zip` sur ton PC, puis glisse **le contenu** du dossier (index.html, app.js, data.js, data2.js, sw.js, manifest.webmanifest et le dossier icons) dans la page. Clique **Commit changes**.
5. Va dans **Settings → Pages**. Dans *Branch*, choisis **main** et **/(root)**, puis **Save**.
6. Après 1 à 2 minutes, l'adresse apparaît en haut de la page : `https://TON-PSEUDO.github.io/japon2026/`.

## Étape 2 – Installer sur le Realme X50 Pro (avec Chrome)
1. Sur le téléphone, ouvre **Chrome** (pas le navigateur Realme) et va à l'adresse ci-dessus.
2. Touche **⋮** (en haut à droite) → **Installer l'application** (ou **Ajouter à l'écran d'accueil**). Tu peux aussi utiliser le bouton **📲 Installer l'appli** dans ⚙️ Filtres.
3. L'icône **Japon 2026** apparaît sur l'écran d'accueil. Ouvre-la depuis cette icône désormais.
4. À la première demande, **autorise la localisation** (pour le bouton 📍 Ma position).

## Étape 3 – Préparer le hors ligne (en Wi-Fi, avant de partir)
Dans l'appli : **⚙️ Filtres → 📴 Mode hors ligne**
- **⬇️ Tous les itinéraires** : enregistre les tracés réels à pied / en voiture.
- **⬇️ Carte de tout le voyage** (~60–80 Mo), ou jour par jour avec **⬇️ Carte du jour choisi**.
Le programme, les trajets, les réservations et le budget fonctionnent sans réseau dès la première ouverture.

## Étape 4 – Transférer tes données du PC vers le téléphone
Les cases cochées, coûts modifiés et réservations sont stockés **sur chaque appareil**.
1. Sur le PC (dans la nouvelle version) : **⚙️ Filtres → 📤 Sauvegarder / transférer** → fichier `Japon2026_mes_donnees.json`.
2. Envoie-le sur le téléphone (mail, OneDrive…).
3. Sur le téléphone : **⚙️ Filtres → 📥 Importer** → choisis le fichier.

## Mettre à jour l'appli plus tard
Remplace les fichiers dans GitHub (**Add file → Upload files**). Le téléphone récupère la nouvelle version à la prochaine ouverture avec réseau (tes données sont conservées).

## Conseils batterie Realme
Paramètres → Batterie → autorise Chrome à fonctionner en arrière-plan si la localisation se coupe. Pense à une batterie externe : GPS + écran consomment beaucoup.
